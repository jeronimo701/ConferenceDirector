# Сторонние компоненты

В комплекте сохраняются исходные бинарные Python runtime, Qt/PySide6, Shiboken, Microsoft runtime и PyInstaller runtime. Встроенные PySide6/Shiboken имеют версию 6.11.0 по архиву ConferenceDirector.exe. Библиотеки не изменялись. Дополнительные тексты лицензий находятся в THIRD-PARTY-*.txt и включены в установщик; собственная лицензия автора их не заменяет.

Qt/PySide: https://doc.qt.io/qtforpython-6/licenses.html ; Qt 6.11.0: https://download.qt.io/archive/qt/6.11/6.11.0/submodules/ ; PySide/Shiboken: https://code.qt.io/cgit/pyside/pyside-setup.git/tree/?h=v6.11.0 . DLL устанавливаются рядом с программой, их можно заменять в собственной рабочей копии. Python: https://github.com/python/cpython ; PyInstaller: https://github.com/pyinstaller/pyinstaller . Microsoft runtime остаётся под исходными условиями Microsoft.

Тексты перенесены из уже подготовленного набора notices MultiToolHub без редактирования; полное происхождение того набора: https://github.com/jeronimo701/MultiToolHub/tree/main/third-party-licenses . Тексты Qt получены из официального дерева qtbase v6.11.0. Модификации сторонних библиотек не заявлены.
