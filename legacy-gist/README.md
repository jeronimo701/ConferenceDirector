# ConferenceDirector — 1.1.2, восстановленные исходники

Актуальная публикация по запросу владельца: комплект с диска D: из `ConferenceDirector 1.1.2/dist/ConferenceDirector`. Номер 1.1.2 взят из названия предоставленной папки; в метаданных исходного EXE версия не указана. Дата сборки исходного EXE — 2026-05-15, SHA-256: `bf7a4a91faa12a57bfbcd7a1a57e2e63cbe38d475f424d97c7d255a9a1d5b312`.

## Готовая программа

[Скачать очищенный установщик 1.1.2](https://gist.githubusercontent.com/jeronimo701/41af1efb9a76718fb741da2cb0ad5249/raw/ConferenceDirectorSetup-1.1.2-clean.exe). Он распаковывает оригинальный EXE и его runtime в выбранную папку; программу автоматически не запускает. Сохранённый conference_director_settings.json исключён. Код исходного EXE не менялся и не подменён пересобранной версией. Старый snapshot-установщик от предыдущей публикации сохранён как прежний вариант.

## Восстановленные исходники

Все 13 собственных модулей извлечены из EXE и восстановлены в читаемые Python-файлы. Это результат декомпиляции с проверенными ручными исправлениями, а не исходные авторские файлы с оригинальными комментариями и форматированием.

Gist хранит файлы в одной папке. Префиксы `src--`, `pyc--` и `dis--` обозначают исходники, исходный извлечённый байткод и дизассемблированное представление. Для восстановления обычных каталогов скачайте/клонируйте весь Gist и выполните:

```
python restore_project.py
cd ConferenceDirector-Recovered/source
python -m pip install -r requirements.txt
python conference_director.py
```

Нужен Python 3.13; проверенная версия — 3.13.12, PySide6 — 6.8.2.1. Для повторной сборки в восстановленной папке source: установите requirements-build.txt и запустите build.ps1 либо `python -m PyInstaller ConferenceDirector.spec`. Spec и build.ps1 созданы заново. Папка original-bytecode сохраняет исходную компилированную форму и требует совместимого Python 3.13; disassembly нужна для аудита восстановления.

## Проверки

- Все 13 модулей компилируются. Сопоставлены все 217 объектов кода: сигнатуры, команды, операнды, переходы и области обработчиков исключений совпали с оригиналом после явно описанной нормализации служебных различий компиляции.
- В отдельных процессах проверены исходный байткод и восстановленные .py на одинаковых синтетических данных: фильтры проектов и музыки, классификация файлов, сохранение настроек, офлайн-разбор Telegram JSON и выбор вложений, таймер, создание главного окна и корректное закрытие. Результаты совпали.
- Исходники прошли самостоятельную сборку PyInstaller; исходная сборка из D: при этом не менялась. Готовая программа для скачивания по-прежнему использует оригинальный EXE.
- Очищенный установщик проверен распаковкой и SHA-256 payload. Исходники, строковые константы и материалы публикации проверены поиском секретов.

Это не формальное доказательство полного совпадения при любых действиях. Сетевой Telegram, внешние плееры/PowerPoint и физическое переключение дисплеев при восстановлении не проверялись и не запускались. Сравнение главных окон выполнено вне реального рабочего стола через Qt offscreen на синтетическом проекте. Сводка и ограничения — RECOVERY-STRUCTURAL.json, RECOVERY-TESTS.json и VALIDATION-1.1.2.json. RECOVERY-INITIAL.json относится к первому проходу декомпилятора, до ручных исправлений.
